# Fonts

`PlusJakartaSans-*.ttf` is the typeface used on the e-RESERVE site, bundled here so the server can draw the
downloadable ticket picture (PHP GD needs a .ttf file). Plus Jakarta Sans is licensed under the SIL Open Font
License 1.1 (https://github.com/tokotype/PlusJakartaSans), which allows redistribution and embedding.
